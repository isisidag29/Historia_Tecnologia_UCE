2012: Las "Soluciones Aisladas"

El 2012 se caracterizó por ser el año de la digitalización descentralizada. Ante la falta de un sistema informático centralizado, las facultades impulsaron sus propios proyectos tecnológicos in-house para sobrevivir a la burocracia de papel, implementando desde controles biométricos hasta bibliotecas digitales de código abierto.

Ficha de Situación: Automatización Local

  • 🏗️ Enfoque: Desarrollo de software departamental por cada facultad.
  • 👤 Actores: Estudiantes tesistas y departamentos de TI locales.
  • 🎯 Objetivo: Eliminar registros manuales y crear repositorios digitales de acceso rápido.
  • 🛡️ Seguridad: Primeros pasos en monitorización central de la red con sistemas Linux (OSSIM) en la DTIC.
Investigación: El Problema del Papel (DSpace UCE, 2012)

"En la actualidad aún se lleva el proceso lento, engorroso e ineficiente para registrar las asistencias a las horas de clase, ya que se basa en registrar mediante un formulario físico y de manera escrita [...] el mismo que implica el desperdicio de tiempo y recursos para transformarlo a un medio digital."

Ver Tesis de Velasco y Villacrés en el Repositorio

1. El Fin de las "Sábanas" de Papel: La Revolución Biométrica

Antes de 2012, el control de docentes y personal era un caos administrativo basado en firmas manuales. Para solucionar esto, facultades como la de Ingeniería implementaron sistemas biométricos de huella dactilar, utilizando dispositivos electrónicos para capturar patrones únicos y generar registros automáticos.

Sistemas Web Locales

Se desarrollaron sistemas web específicos para procesos como inscripciones de "Suficiencia Informática", permitiendo el acceso remoto por primera vez.

Bibliotecas Open Source

Ciencias Médicas creó un portal virtual sustentado en software de código abierto para catalogar material digital, audio y multimedia.

Imagen. El desarrollo de interfaces propias fue la norma antes de la unificación de sistemas.

2. Panorama de Desarrollo Tecnológico Institucional

El 2012 marcó el inicio de la modernización de la gestión universitaria, reemplazando métodos análogos con soluciones tecnológicas aplicadas a cada necesidad específica.
